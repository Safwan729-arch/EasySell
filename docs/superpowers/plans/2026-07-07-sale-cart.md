# Sale Cart Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a shopkeeper stage multiple products into a running cart (from Inventory or camera scan) and commit them all in one atomic checkout, instead of recording each sale one at a time.

**Architecture:** Pure Dart cart math + receipt-grouping (testable, no I/O) + a new atomic `record_sale_cart` Postgres RPC (all-or-nothing, sibling to `record_sale`) + a small Riverpod cart module wired into the existing Inventory/Scan/History screens. No feature flag — this replaces the app's only sale-entry path, so a flag would mean maintaining two parallel flows.

**Tech Stack:** Flutter, Riverpod, `supabase_flutter` (`.rpc`), `freezed`, Postgres/plpgsql (Supabase SQL Editor, no CLI).

**Branch:** `feat/sale-cart` · **Rollback:** `git checkout checkpoint-pre-cart`

**Spec:** `docs/superpowers/specs/2026-07-07-sale-cart-design.md`

## Global Constraints

- Sales must go through `record_sale_cart` (multi-item) — never client-side stock math, never a per-line loop of separate RPC calls from Flutter.
- Checkout is all-or-nothing: one failing line must roll back the entire checkout (enforced by running the whole loop inside one plpgsql function call).
- Prices are frozen onto each transaction row at checkout time (already true of `record_sale`; `record_sale_cart` must do the same).
- Restock is unchanged — still commits instantly via `record_restock`, no cart involvement.
- RLS already covers `transactions`/`products` via existing shop-scoped policies (`0001_init.sql`) — no new policy needed.
- No new dependency — everything is built from packages already in `pubspec.yaml` (`flutter_riverpod`, `freezed_annotation`, `supabase_flutter`, `go_router`).

```sql
-- =============================================================================
-- 0007_sale_cart.sql — multi-item cart checkout.
-- Run AFTER 0006_dashboard_summary_day.sql (Dashboard SQL Editor -> paste -> Run).
-- Idempotent (safe to re-run).
--
-- Adds sale_group_id (nullable) to transactions: every line inserted by one
-- record_sale_cart call shares the same id, so Sales History can group them
-- into a single "receipt" row. Existing rows stay null and keep rendering as
-- their own single-line receipt -- no backfill needed.
--
-- record_sale_cart mirrors record_sale but commits a whole cart atomically:
-- the entire loop runs inside this one function call, which Postgres executes
-- as a single transaction, so any raise exception (stock ran out on one line,
-- bad product id) rolls back every row lock, stock decrement, and insert made
-- earlier in the same checkout. There is no partial checkout.
-- =============================================================================

alter table transactions add column if not exists sale_group_id uuid;
create index if not exists idx_transactions_sale_group on transactions (shop_id, sale_group_id);

drop function if exists record_sale_cart(uuid, jsonb, text);

create function record_sale_cart(
  p_shop_id uuid,
  p_items jsonb,              -- [{"product_id": "...", "quantity": 2}, ...]
  p_source text default 'manual'
) returns setof transactions
language plpgsql
as $$
declare
  v_group uuid := gen_random_uuid();
  v_item record;
  v_product products;
begin
  if p_items is null or jsonb_array_length(p_items) = 0 then
    raise exception 'Cart is empty';
  end if;

  for v_item in
    select * from jsonb_to_recordset(p_items) as x(product_id uuid, quantity numeric)
  loop
    if v_item.quantity is null or v_item.quantity <= 0 then
      raise exception 'Quantity must be greater than zero';
    end if;

    select * into v_product from products
      where id = v_item.product_id and shop_id = p_shop_id
      for update;

    if v_product is null then
      raise exception 'Product not found';
    end if;

    if v_product.quantity < v_item.quantity then
      raise exception 'Insufficient stock for %: have %, need %',
        v_product.name, v_product.quantity, v_item.quantity;
    end if;

    update products set quantity = quantity - v_item.quantity, updated_at = now()
      where id = v_item.product_id;

    insert into transactions(shop_id, product_id, type, quantity, buying_price,
                              selling_price, source, sale_group_id)
    values (p_shop_id, v_item.product_id, 'sale', v_item.quantity,
            v_product.buying_price, v_product.selling_price, p_source, v_group);
  end loop;

  return query select * from transactions where sale_group_id = v_group;
end;
$$;
```

```dart
import '../../inventory/domain/product.dart';
import 'cart_line.dart';

/// Adds [quantity] of [product] to [lines], merging into an existing line for
/// the same product if present. The resulting quantity for that product is
/// clamped to [Product.quantity] (current stock) so the cart can never stage
/// more of an item than physically exists, even across repeated adds.
List<CartLine> addOrIncrementLine(
  List<CartLine> lines,
  Product product,
  double quantity,
) {
  final index = lines.indexWhere((l) => l.product.id == product.id);
  if (index == -1) {
    final clamped = quantity.clamp(0, product.quantity).toDouble();
    return clamped <= 0
        ? lines
        : [...lines, CartLine(product: product, quantity: clamped)];
  }
  final existing = lines[index];
  final merged =
      (existing.quantity + quantity).clamp(0, product.quantity).toDouble();
  final updated = [...lines];
  updated[index] = existing.copyWith(quantity: merged);
  return updated;
}

/// How much more of [product] can be added right now: current stock minus
/// whatever quantity of it is already staged in [lines]. Never negative.
double remainingStockForLines(List<CartLine> lines, Product product) {
  final staged = lines
      .where((l) => l.product.id == product.id)
      .fold<double>(0, (sum, l) => sum + l.quantity);
  final remaining = product.quantity - staged;
  return remaining < 0 ? 0 : remaining;
}

/// Sets the line for [productId] to exactly [quantity], clamped to that
/// product's current stock. A quantity at/below zero removes the line.
List<CartLine> updateLineQuantity(
  List<CartLine> lines,
  String productId,
  double quantity,
) {
  if (quantity <= 0) return removeLine(lines, productId);
  final index = lines.indexWhere((l) => l.product.id == productId);
  if (index == -1) return lines;
  final clamped = quantity.clamp(0, lines[index].product.quantity).toDouble();
  final updated = [...lines];
  updated[index] = lines[index].copyWith(quantity: clamped);
  return updated;
}

List<CartLine> removeLine(List<CartLine> lines, String productId) =>
    lines.where((l) => l.product.id != productId).toList();

/// Sum of every line's subtotal (unit selling price x quantity).
double cartTotal(List<CartLine> lines) =>
    lines.fold(0, (sum, l) => sum + l.subtotal);

/// The wire shape `record_sale_cart` expects for its `p_items` jsonb array.
List<Map<String, dynamic>> cartItemsPayload(List<CartLine> lines) => [
  for (final l in lines) {'product_id': l.product.id, 'quantity': l.quantity},
];

/// Quantity-stepper increment matched to how a product is sold: whole units
/// for pieces, fractional for weight/volume. Used by the add-to-cart sheet
/// and the cart screen's line stepper.
double stepForUnit(ProductUnit unit) => switch (unit) {
  ProductUnit.pcs => 1,
  ProductUnit.kg => 0.5,
  ProductUnit.g => 50,
  ProductUnit.litre => 0.5,
  ProductUnit.ml => 50,
};
```

```dart
/// One row in Sales History: either a single ungrouped sale or every line
/// from one cart checkout, grouped by `sale_group_id`. Transactions with no
/// group id (manual/voice/single-scan sales, and every pre-cart historical
/// row) become their own singleton receipt, keyed by their own transaction id
/// so they never merge with another ungrouped sale.
class SaleReceipt {
  const SaleReceipt({required this.id, required this.lines});

  final String id;
  final List<Transaction> lines;

  DateTime? get createdAt => lines.first.createdAt;
  double get totalRevenue => lines.fold<double>(0, (sum, t) => sum + t.revenue);
  int get lineCount => lines.length;
}

/// Groups [sales] into receipts by `saleGroupId`, preserving each receipt's
/// first-seen order in [sales].
List<SaleReceipt> groupSalesIntoReceipts(List<Transaction> sales) {
  final byGroup = <String, List<Transaction>>{};
  final order = <String>[];
  for (final t in sales) {
    final key = t.saleGroupId ?? 'single-${t.id}';
    if (!byGroup.containsKey(key)) order.add(key);
    byGroup.putIfAbsent(key, () => []).add(t);
  }
  return [for (final key in order) SaleReceipt(id: key, lines: byGroup[key]!)];
}
```

```dart
  /// Atomic multi-item checkout: commits every cart line in one Postgres
  /// transaction via `record_sale_cart`, or none of them if any line fails
  /// (e.g. insufficient stock). Returns the inserted rows, all sharing one
  /// `sale_group_id` so History can group them into a single receipt.
  Future<Result<List<Transaction>>> recordSaleCart({
    required String shopId,
    required List<Map<String, dynamic>> items,
    String source = 'manual',

    try {
      final result = await _client.rpc(
        'record_sale_cart',
        params: {'p_shop_id': shopId, 'p_items': items, 'p_source': source},
      );
      final rows = result as List;
      return Result.success([
        for (final r in rows)
          Transaction.fromJson(Map<String, dynamic>.from(r as Map)),
      ]);
    } catch (e) {
      return Result.failure(_map(e));
    }
  }
```

```dart
import '../../../core/error/failure.dart';

/// Drives the checkout action. Mirrors `TransactionController`: the cart's
/// contents live in [CartController] (always synchronously available so the
/// Cart screen can render the line list); this controller only models the
/// in-flight checkout call, so a loading/error state never hides the cart
/// itself.
class CartCheckoutController extends AsyncNotifier<void> {
  @override
  FutureOr<void> build() {}

  Future<bool> checkout({String source = 'manual'}) async {
    final shopId = ref.read(myShopProvider).value?.id;
    final lines = ref.read(cartControllerProvider);
    if (shopId == null) {
      state = AsyncError(
        const AuthFailure('No shop found for this account.'),
        StackTrace.current,
      );
      return false;
    }
    if (lines.isEmpty) return false;

    state = const AsyncLoading();
    final result = await ref
        .read(transactionRepositoryProvider)
        .recordSaleCart(
          shopId: shopId,
          items: cartItemsPayload(lines),
          source: source,
        );
    return result.when(
      success: (_) {
        ref.read(cartControllerProvider.notifier).clear();
        ref.invalidate(productsStreamProvider);
        ref.read(dataRefreshProvider.notifier).bump();
        state = const AsyncData(null);
        return true;
      },
      failure: (f) {
        state = AsyncError(f, StackTrace.current);
        return false;
      },
    );
  }
}

final cartCheckoutControllerProvider =
    AsyncNotifierProvider<CartCheckoutController, void>(
      CartCheckoutController.new,
```

```dart
/// Drives the scan flow: opens the camera immediately, recognizes, then routes
/// to add-to-cart / chooser / manual pick. A successful add reopens the camera
/// so a shopkeeper can scan a customer's items back-to-back; the AppBar back
/// arrow exits to Inventory, where the global cart bar reflects everything
/// scanned so far. Cart items still only commit via the Cart screen's
/// checkout -- scanning never auto-commits a sale.
class ScanScreen extends ConsumerStatefulWidget {
  const ScanScreen({super.key});

  @override
  ConsumerState<ScanScreen> createState() => _ScanScreenState();
}

class _ScanScreenState extends ConsumerState<ScanScreen> {
  bool _busy = true;
  String? _error;

  @override
  void initState() {
    super.initState();
    WidgetsBinding.instance.addPostFrameCallback((_) => _run());
  }

  Future<void> _run() async {
    while (true) {
      setState(() {
        _busy = true;
        _error = null;
      });
      try {
        final outcome = await ref
            .read(scanControllerProvider)
            .captureAndRecognize();
        if (!mounted) return;
        if (outcome == null) {
          context.pop(); // user cancelled the camera
          return;
        }
        final again = await _route(outcome);
        if (!again) return;
      } catch (e) {
        if (!mounted) return;
        setState(
          () => _error = e is Failure ? e.message : 'Scan failed. Try again.',
        );
        return;
      } finally {
        if (mounted) setState(() => _busy = false);
      }
    }
  }

  /// Routes a recognition outcome. Returns true to keep scanning (the loop in
  /// [_run] reopens the camera for another shot), false to exit the screen.
  Future<bool> _route(ScanOutcome outcome) async {
    switch (outcome.action) {
      case ScanAction.autoSell:
        if (outcome.products.isEmpty) return _noMatch();
        return _addToCart(outcome.products.first);
      case ScanAction.chooseFromMatches:
        final picked = await showProductPickerSheet(
          context,
          products: outcome.products,
          title: 'Did you mean?',
        );
        if (picked == null) {
          if (mounted) context.pop();
          return false;
        }
        return _addToCart(picked);
      case ScanAction.noMatch:
        return _noMatch();
    }
  }

  /// Adds one unit of [product] to the cart. Always returns true (keep
  /// scanning) -- the AppBar back arrow, not a successful add, is how a
  /// shopkeeper exits to review the cart.
  Future<bool> _addToCart(Product product) async {
    ref.read(cartControllerProvider.notifier).addOrIncrement(product, 1);
    AppHaptics.success();
    if (mounted) {
      ScaffoldMessenger.of(context)
        ..hideCurrentSnackBar()
        ..showSnackBar(SnackBar(content: Text('Added ${product.name} to cart')));
    }
    return true;
  }

  Future<bool> _noMatch() async {
    // Manual fallback pulls the full catalog from the inventory stream.
    final all = ref.read(_allProductsForPicker);
    final picked = await showProductPickerSheet(
      context,
      products: all,
      title: 'No match — pick the product',
    );
    if (picked == null) {
      if (mounted) context.pop();
      return false;
    }
    return _addToCart(picked);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Scan product')),
      body: Center(
        child: _error != null
            ? Column(
                mainAxisSize: MainAxisSize.min,
                children: [
                  const Icon(Icons.error_outline, size: 48),
                  const SizedBox(height: 12),
                  Padding(
                    padding: const EdgeInsets.symmetric(horizontal: 32),
                    child: Text(_error!, textAlign: TextAlign.center),
                  ),
                  const SizedBox(height: 12),
                  FilledButton(onPressed: _run, child: const Text('Retry')),
                ],
              )
            : _busy
            ? const CircularProgressIndicator()
            : const SizedBox.shrink(),
      ),
    );
  }
}
```

```dart
class SaleReceipt {

  final List<Transaction> lines;

    byGroup.putIfAbsent(key, () => []).add(t);
  }
  return [for (final key in order) SaleReceipt(id: key, lines: byGroup[key]!)];

/// A receipt paired with its resolved product name(s), ready to render and
/// sort. Single-line receipts behave exactly like the pre-cart per-sale rows;
/// multi-line receipts (cart checkouts) summarize as "N items".
class _ReceiptRow {
  _ReceiptRow({required this.receipt, required this.names});

  final SaleReceipt receipt;
  final Map<String, String> names; // productId -> name, for every line

  bool get isSingle => receipt.lineCount == 1;

  String get displayName {
    if (isSingle) {
      final name = names[receipt.lines.single.productId] ?? '';
      return name.isEmpty ? 'Sale' : name;
    }
    return '${receipt.lineCount} items';
  }

  /// Lower-cased sort key. Grouped receipts sort after named single sales
  /// (prefixed so they cluster together, ordered by their own display name).
  String get sortName {
    if (!isSingle) return '~~ $displayName'.toLowerCase();
    final name = (names[receipt.lines.single.productId] ?? '').toLowerCase();
    return name.isEmpty ? '~' : name;
  }

  /// Sort/display value for the Qty column: the actual quantity for a single
  /// sale, or the line count for a grouped checkout (mixed units can't sum
  /// meaningfully, so item count is the closest comparable proxy).
  double get qtyValue =>
      isSingle ? receipt.lines.single.quantity : receipt.lineCount.toDouble();

  String get qtyLabel {
    if (!isSingle) return '${receipt.lineCount}';
    final qty = receipt.lines.single.quantity;
    return qty == qty.roundToDouble() ? qty.toStringAsFixed(0) : qty.toString();
  }

  /// True if any line's product name contains [query] (or [query] is empty).
  bool matches(String query) {
    if (query.isEmpty) return true;
    for (final t in receipt.lines) {
      if ((names[t.productId] ?? '').toLowerCase().contains(query)) return true;
    }
    return false;
  }
}

class _HeaderRow extends StatelessWidget {

class _HeaderCell extends StatelessWidget {
  const _HeaderCell({
    required this.label,
    required this.active,
    required this.ascending,
    required this.onTap,
    this.width,
    this.align = TextAlign.left,
    this.accent = false,
  });

  final String label;
  final bool active;
  final bool ascending;
  final VoidCallback onTap;
  final double? width;
  final TextAlign align;

  /// The Amount column is tinted brand-blue to signal it's the primary
  /// find-by-value affordance, even when it isn't the active sort.
  final bool accent;

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    final scheme = theme.colorScheme;
    final color = accent || active
        ? scheme.primary
        : scheme.onSurfaceVariant;
    final isRight = align == TextAlign.right;
    final isCenter = align == TextAlign.center;

    final cell = InkWell(
      onTap: onTap,
      borderRadius: BorderRadius.circular(8),
      child: Padding(
        padding: const EdgeInsets.symmetric(vertical: 8, horizontal: 2),
        child: Row(
          mainAxisAlignment: isRight
              ? MainAxisAlignment.end
              : isCenter
              ? MainAxisAlignment.center
              : MainAxisAlignment.start,
          children: [
            Flexible(
              child: Text(
                label,
                textAlign: align,
                overflow: TextOverflow.ellipsis,
                style: theme.textTheme.labelMedium?.copyWith(
                  color: color,
                  fontWeight: FontWeight.w700,
                  letterSpacing: 0.2,
                ),
              ),
            ),
            if (active)
              Icon(
                ascending ? Icons.arrow_upward : Icons.arrow_downward,
                size: 13,
                color: color,
              ),
          ],
        ),
      ),
    );

    return width == null ? Expanded(child: cell) : SizedBox(width: width, child: cell);
  }
}

/// One receipt: a summary row (Time · Item(s) · Qty · Amount), expandable into
/// its individual lines when it came from a multi-item cart checkout.
class _ReceiptTile extends StatefulWidget {
  const _ReceiptTile({required this.row, required this.currency});

  final _ReceiptRow row;
  final String currency;

  @override
  State<_ReceiptTile> createState() => _ReceiptTileState();
}

class _ReceiptTileState extends State<_ReceiptTile> {
  bool _expanded = false;

  String _time(DateTime? d) {
    final t = (d ?? DateTime.now()).toLocal();
    final h = t.hour % 12 == 0 ? 12 : t.hour % 12;
    final m = t.minute.toString().padLeft(2, '0');
    final ampm = t.hour < 12 ? 'AM' : 'PM';
    return '$h:$m$ampm';
  }

  String _lineQty(double v) =>
      v == v.roundToDouble() ? v.toStringAsFixed(0) : v.toString();

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    final scheme = theme.colorScheme;
    final row = widget.row;
    final canExpand = !row.isSingle;

    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        InkWell(
          onTap: canExpand ? () => setState(() => _expanded = !_expanded) : null,
          child: Padding(
            padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 11),
            child: Row(
              children: [
                SizedBox(
                  width: _timeW,
                  child: Text(
                    _time(row.receipt.createdAt),
                    style: theme.textTheme.bodySmall?.copyWith(
                      color: scheme.onSurfaceVariant,
                    ),
                  ),
                ),
                Expanded(
                  child: Padding(
                    padding: const EdgeInsets.only(right: 8),
                    child: Row(
                      children: [
                        Flexible(
                          child: Text(
                            row.displayName,
                            maxLines: 1,
                            overflow: TextOverflow.ellipsis,
                            style: theme.textTheme.bodyMedium?.copyWith(
                              fontWeight: FontWeight.w600,
                            ),
                          ),
                        ),
                        if (canExpand) ...[
                          const SizedBox(width: 4),
                          Icon(
                            _expanded ? Icons.expand_less : Icons.expand_more,
                            size: 16,
                            color: scheme.onSurfaceVariant,
                          ),
                        ],
                      ],
                    ),
                  ),
                ),
                SizedBox(
                  width: _qtyW,
                  child: Text(
                    row.qtyLabel,
                    textAlign: TextAlign.center,
                    style: theme.textTheme.bodyMedium?.copyWith(
                      color: scheme.onSurfaceVariant,
                    ),
                  ),
                ),
                SizedBox(
                  width: _amtW,
                  child: Text(
                    Money.compact(row.receipt.totalRevenue, currencyCode: widget.currency),
                    textAlign: TextAlign.right,
                    style: theme.textTheme.bodyMedium?.copyWith(
                      fontWeight: FontWeight.w800,
                    ),
                  ),
                ),
              ],
            ),
          ),
        ),
        if (_expanded)
          for (final line in row.receipt.lines)
            Padding(
              padding: const EdgeInsets.fromLTRB(12, 0, 12, 8),
              child: Row(
                children: [
                  const SizedBox(width: _timeW),
                  Expanded(
                    child: Text(
                      (row.names[line.productId]?.isNotEmpty ?? false)
                          ? row.names[line.productId]!
                          : 'Sale',
                      style: theme.textTheme.bodySmall?.copyWith(
                        color: scheme.onSurfaceVariant,
                      ),
                    ),
                  ),
                  SizedBox(
                    width: _qtyW,
                    child: Text(
                      _lineQty(line.quantity),
                      textAlign: TextAlign.center,
                      style: theme.textTheme.bodySmall?.copyWith(
                        color: scheme.onSurfaceVariant,
                      ),
                    ),
                  ),
                  SizedBox(
                    width: _amtW,
                    child: Text(
                      Money.compact(line.revenue, currencyCode: widget.currency),
                      textAlign: TextAlign.right,
                      style: theme.textTheme.bodySmall?.copyWith(
                        color: scheme.onSurfaceVariant,
                      ),
                    ),
                  ),
                ],
              ),
            ),
      ],
    );
  }
}
```
