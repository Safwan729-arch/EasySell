# EasySell app name and launcher icon — design

**Date:** 2026-10-15 · **Status:** built, installed on the S22
**Path:** bounded, so there is no separate plan. It was agreed in chat.

## 1. What changed

- Name under the icon: **EasySell** (Android `android:label`, iOS
  `CFBundleDisplayName`). Also changed: `MaterialApp.title` (Android recents),
  the iOS microphone permission text, and the login screen heading.
- Launcher icon: the logo's mark (phone + box + leaf + mic + camera) in
  dark green `#183C2A` on white. It is generated by `flutter_launcher_icons`
  from `flutter_launcher_icons.yaml`.

## 2. Decisions

| Decision | Why |
|---|---|
| **The icon leaves out the word "EasySell"** | At icon size the word is unreadable, and the launcher already prints the name under the icon. The user agreed. |
| **The app ID and Dart package stay `ai_shopkeeper`** | Changing `applicationId` makes Android treat it as a different app: it installs a second copy and loses the login. Only the visible name changed. |
| **Adaptive foreground has the mark at ~59% height** (legacy/iOS: ~80%) | The first build used 49% (68%) so all of it fit Android's guaranteed 66% safe circle, but **on the S22 it looked too small** and the user asked for it bigger. At 59% the mark fills the icon. Samsung's default rounded-square mask shows it whole. The accepted cost is that a launcher with strict *circle* icons may trim the phone outline's rounded corners (the mic and camera badges sit mid-height and stay inside). |
| **White background** | Matches the logo as designed. |

## 3. Gotchas

- **The source logo's "transparency" is fake.**
  `assets/branding/Gemini_Generated_Image_*.jpg` is a JPG with a grey/white
  checkerboard *painted in*. Using it directly would put a checkerboard on the
  home screen. `icon.png` and `icon_foreground.png` were cut out by brightness
  (mark L≈45, checkerboard 197/255; alpha ramps between L 70 and 165). The
  ~300 px mark was then enlarged with a bicubic-scaled alpha re-sharpened by a
  smoothstep, so edges stay crisp at 1024 px instead of blurring. The
  throwaway PowerShell/C# script lived in the session scratchpad and was not
  kept. If the designer supplies a real PNG/SVG, replace the two PNGs and
  rerun `dart run flutter_launcher_icons`.
- **`flutter_launcher_icons` 0.14.4 corrupts `project.pbxproj`.** It
  rewrote `ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS = YES`
  to `= AppIcon`. That change was reverted, and the icon set name was already
  `AppIcon`. **Check `git diff ios/Runner.xcodeproj` after every regenerate.**
